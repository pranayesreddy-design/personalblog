# Krishna Pranay Blog

A modular static blog starter with 3 sections:

- Travel
- Thoughts
- Trading

## Quick start

Run a local static server from the project root:

`python3 -m http.server 8080`

Then open [http://localhost:8080](http://localhost:8080).

## Edit content

- Update section metadata in `assets/js/site-config.js`.
- Update section post lists in `content/sections/*.json`.
- Update full article content in `content/posts/<section>/*.json`.
- Add/update images in `assets/images/posts/<section>/`.

## Add new sections/pages

Follow the exact conventions in `RULEBOOK.md`.

Helpful starter files:

- `NEW_POST_TEMPLATE.json`
- `NEW_SECTION_CHECKLIST.md`
